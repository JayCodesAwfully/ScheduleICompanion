SCHEDULE I COMPANION v1.6.0
============================

1. Extract the entire ZIP. Keep the Payload folder beside ScheduleICompanion-Setup.exe.
2. Close Schedule I.
3. Run ScheduleICompanion-Setup.exe and approve the administrator prompt.
4. Confirm the detected Schedule I folder, then choose Install / Repair.
5. Launch Schedule I normally through Steam. The Companion starts automatically with the game.

The setup application can install the official MelonLoader v0.7.3 x64 release when it is not
already present. That download is verified against a pinned SHA-256 hash before extraction.

Repair is safe to run again and creates a timestamped backup first. Uninstall removes only the
Companion; MelonLoader and settings under LocalAppData are deliberately preserved.

Managed mods are available from the Companion's Mods tab. Close the game before enabling,
updating, or disabling them. Disabling the Personal Backpack removes only its DLL and keeps
all backpack recovery data.

Official MelonLoader releases:
https://github.com/LavaGang/MelonLoader/releases
